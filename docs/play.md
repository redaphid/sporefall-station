# How to Play Backseat

Two ways to play. The browser one is easiest.

## Play in the browser (easiest, always the newest version)

Open this link on any phone, tablet, or computer:

**https://backseat-sd8.pages.dev**

That's it — no installing. It's always the latest version.

**Put it on your home screen (so it opens like an app):**

- **iPhone / iPad (Safari):** tap the **Share** button, then **Add to Home Screen**.
- **Android (Chrome):** tap the **⋮** menu (top right), then **Add to Home screen** / **Install app**.

Now there's a game icon on your phone. Tap it to play.

> Note: To play the 2-phone Bluetooth co-op mode, you need the Android app below.
> The browser version is great for playing on your own.

## Install the Android app (for 2-phone co-op)

1. On your Android phone, open this link — it downloads the app straight from the
   game site (always the newest version):
   **https://backseat-sd8.pages.dev/download**
2. Tap the downloaded **`backseat.apk`** to install it. The first time, Android asks
   to **allow installing apps from this source** — say yes, then tap **Install**.

   (Prefer the source page? The same file is on the releases page:
   https://github.com/redaphid/mobile-streets-of-rogue/releases/latest)

Open **Backseat** from your app drawer and play.

**You only install once — it updates itself.** When you're online, the app
quietly grabs the newest version in the background and uses it next time you
open it. No re-downloading.

> When do you still need a new `.apk`? Only for big changes to the app itself
> (new Bluetooth features, etc.). For those, come back to the same releases link
> and install the newest `.apk` over the old one.

> Heads up: right now the app is a *debug* build, so a brand-new `.apk` might
> ask you to uninstall the old one first. That gets smoother once signed
> releases are set up.
